KODA CUT - BIBLIOTECA

O aplicativo cria automaticamente:
- biblioteca\videos
- biblioteca\imagens
- biblioteca\audios

Use a aba "ARQUIVOS / ELEMENTOS" para adicionar os arquivos.
Cada item recebe um ID estavel baseado no nome, por exemplo:
- video:broll_praia
- image:logo_koda
- audio:boom

O prompt/KodaScript usa esses IDs para posicionar cada elemento na timeline.
